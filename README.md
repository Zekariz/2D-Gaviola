## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) with **Unity 6000.3.24f1 LTS** installed
- [Git](https://git-scm.com/)
- [Git LFS](https://git-lfs.com/)

### Clone the repository

```bash
git clone https://github.com/Zekariz/2D-Gaviola.git
cd 2D-Gaviola
git lfs install
git lfs pull
```
